HƯỚNG DẪN SỬ DỤNG
=================

1. Kiểm tra source
------------------
Dự án viết bằng Python nên không cần biên dịch như C/C++/Java. Để kiểm tra nhanh lỗi cú pháp, chạy:

python -m py_compile src/pipeline.py scripts/preprocess_smd.py scripts/preprocess_hai.py scripts/preprocess_exathlon.py scripts/pilot_rank_jepa_pad_cached.py scripts/build_pair_rule_common.py scripts/build_domain_shift_smd.py scripts/build_domain_shift_hai.py scripts/build_domain_shift_exathlon.py scripts/run_domain_shift_case_matrix.py scripts/run_manifest_benchmarks.py

Để xem tham số pipeline chính:

python -m src.pipeline --help

2. Quy ước thí nghiệm chính
---------------------------
Các lệnh dưới đây dùng cấu hình full experiment để lấy kết quả chính, không phải smoke-test:

- Dataset: SMD, HAI, Exathlon.
- Mode chạy tự động trong benchmark: `uad_source` và `adaptnas_combined`.
- One-class learning backend: `deepsvdd`, `gmm_head`, `lof_head`.
- NAS strategy: `evolutionary_guided`.
- Rule chọn pair:
  SMD và HAI dùng `cross_entity_paper_safe`.
  Exathlon dùng `cross_entity_same_app_stable_adaptation_window`.

Nếu máy không có GPU, thay toàn bộ `--device cuda` thành `--device cpu`.

3. Tiền xử lý dữ liệu
---------------------
SMD:

python scripts/preprocess_smd.py --raw_root data/ServerMachineDataset --out_root data/smd --window 128 --stride 64

HAI 21.03:

python scripts/preprocess_hai.py --raw_root external/hai --version 21.03 --out_root data/hai --window 128 --stride 64

Exathlon:

python scripts/preprocess_exathlon.py --raw_root external/exathlon --out_root data/exathlon --window 128 --stride 64 --scale_on normal_rows

4. Chọn source-target pairs bằng best explainable rule
------------------------------------------------------
SMD cần bước ranking PAD trước khi build manifest:

python scripts/pilot_rank_jepa_pad_cached.py `
  --data_root data/smd `
  --dataset_name smd_cross_entity_all `
  --pair_scope cross_entity_all `
  --out_dir outputs/benchmarks/jepa_pad_smd_cross_entity_all `
  --device cuda `
  --epochs 10 `
  --topk 100

Sau đó build manifest SMD theo rule `cross_entity_paper_safe`:

python scripts/build_domain_shift_smd.py `
  --data_root data/smd `
  --out_root data/smd_experiments `
  --pair_rule cross_entity_paper_safe `
  --rankings_json outputs/benchmarks/jepa_pad_smd_cross_entity_all/pilot_rankings.json `
  --global_topk 3 `
  --seed 42

HAI cũng cần ranking PAD trước khi build manifest:

python scripts/pilot_rank_jepa_pad_cached.py `
  --data_root data/hai `
  --dataset_name hai_cross_entity_all `
  --pair_scope cross_entity_all `
  --out_dir outputs/benchmarks/jepa_pad_hai_cross_entity_all `
  --device cuda `
  --epochs 10 `
  --topk 100

Sau đó build manifest HAI theo rule `cross_entity_paper_safe`:

python scripts/build_domain_shift_hai.py `
  --data_root data/hai `
  --out_root data/hai_experiments `
  --pair_rule cross_entity_paper_safe `
  --rankings_json outputs/benchmarks/jepa_pad_hai_cross_entity_all/pilot_rankings.json `
  --global_topk 3 `
  --seed 42

Exathlon dùng stable adaptation-window rule, không cần truyền ranking JSON:

python scripts/build_domain_shift_exathlon.py `
  --data_root data/exathlon `
  --out_root data/exathlon_experiments `
  --pair_rule cross_entity_same_app_stable_adaptation_window `
  --seed 42

Các manifest chính sau khi build:

data/smd_experiments/cross_entity_paper_safe/manifest.json
data/hai_experiments/cross_entity_paper_safe/manifest.json
data/exathlon_experiments/cross_entity_same_app_stable_adaptation_window/manifest.json

5. Chạy full benchmark cho 2 mode và 3 one-class backends
---------------------------------------------------------
Đặt cấu hình chung trong PowerShell:

$COMMON = @(
  "--output_root", "outputs/benchmarks/main_rule_oneclass_plugin_sweep_gpu",
  "--device", "cuda",
  "--seed", "42",
  "--epochs_pretrain", "10",
  "--search_candidates", "5",
  "--nas_search_iters", "3",
  "--nas_search_strategy", "evolutionary_guided",
  "--combined_nas_topk_rerank", "5",
  "--batch_size", "64",
  "--oneclass_epochs", "10",
  "--oneclass_final_epochs", "20",
  "--oneclass_batch_size", "1024",
  "--oneclass_max_fit", "5000"
)

Chạy SMD:

foreach ($oc in @("deepsvdd", "gmm_head", "lof_head")) {
  python scripts/run_manifest_benchmarks.py `
    --manifest data/smd_experiments/cross_entity_paper_safe/manifest.json `
    --dataset_name "smd_paper_safe_${oc}_gpu" `
    @COMMON `
    --oneclass_method $oc `
    --weighting_oneclass_method $oc `
    --final_oneclass_method $oc
}

Chạy HAI:

foreach ($oc in @("deepsvdd", "gmm_head", "lof_head")) {
  python scripts/run_manifest_benchmarks.py `
    --manifest data/hai_experiments/cross_entity_paper_safe/manifest.json `
    --dataset_name "hai_paper_safe_${oc}_gpu" `
    @COMMON `
    --oneclass_method $oc `
    --weighting_oneclass_method $oc `
    --final_oneclass_method $oc
}

Chạy Exathlon:

foreach ($oc in @("deepsvdd", "gmm_head", "lof_head")) {
  python scripts/run_manifest_benchmarks.py `
    --manifest data/exathlon_experiments/cross_entity_same_app_stable_adaptation_window/manifest.json `
    --dataset_name "exathlon_same_app_stable_adaptation_window_${oc}_gpu" `
    @COMMON `
    --oneclass_method $oc `
    --weighting_oneclass_method $oc `
    --final_oneclass_method $oc
}

Mỗi lệnh `run_manifest_benchmarks.py` tự chạy đúng hai mode `uad_source` và `adaptnas_combined`, đồng thời sinh báo cáo so sánh fixed baselines và NAS baselines.

Kết quả nằm trong:

outputs/benchmarks/main_rule_oneclass_plugin_sweep_gpu/<dataset_name>/
  summary.json
  REPORT.md
  <source_entity>__to__<target_entity>/

Nếu muốn chạy lại dù thư mục kết quả đã tồn tại, thêm `--force_run` vào cuối lệnh benchmark.

6. Thí nghiệm NAS trên paper frameworks
---------------------------------------
Trong phạm vi dataset SMD/HAI/Exathlon, repo hiện có paper-style NAS cho raw SMD với `OmniAnomaly` và `TranAD`. `USAD` trong repo là đường SWaT source-only nên không nằm trong gói HAI/SMD/Exathlon này.

Chạy OmniAnomaly partial NAS trên các máy SMD xuất hiện trong rule chính:

$SMD_MACHINES = @("machine-1-1", "machine-1-4", "machine-1-8", "machine-2-4")
New-Item -ItemType Directory -Force outputs/benchmarks/paper_framework_nas_smd | Out-Null

foreach ($m in $SMD_MACHINES) {
  python -m src.pipeline `
    --mode uad_source `
    --family omni_anomaly `
    --raw_smd_root data/ServerMachineDataset `
    --machine $m `
    --search_candidates 20 `
    --omni_search_iters 3 `
    --omni_epochs 20 `
    --omni_final_epochs 20 `
    --device cuda
  Copy-Item outputs/results.json "outputs/benchmarks/paper_framework_nas_smd/omni_anomaly_${m}.json" -Force
}

Chạy TranAD partial NAS trên cùng nhóm máy SMD:

foreach ($m in $SMD_MACHINES) {
  python -m src.pipeline `
    --mode uad_source `
    --family tranad `
    --raw_smd_root data/ServerMachineDataset `
    --machine $m `
    --search_candidates 5 `
    --tranad_search_iters 2 `
    --tranad_epochs 5 `
    --tranad_final_epochs 5 `
    --device cuda
  Copy-Item outputs/results.json "outputs/benchmarks/paper_framework_nas_smd/tranad_${m}.json" -Force
}

7. Cách đọc kết quả
-------------------
Ưu tiên đọc các file:

outputs/benchmarks/main_rule_oneclass_plugin_sweep_gpu/<dataset_name>/REPORT.md
outputs/benchmarks/main_rule_oneclass_plugin_sweep_gpu/<dataset_name>/summary.json

Trong `REPORT.md`, các cột quan trọng là:

- `uad_source`: kết quả mode source-only.
- `combined`: kết quả mode `adaptnas_combined`.
- `best_NAS`: kiến trúc NAS tốt nhất trong nhóm ứng viên.
- `best_fixed`: baseline kiến trúc cố định tốt nhất.
- `d_combined-source AUROC`: chênh lệch AUROC giữa combined và source-only.
- `d_bestNAS-fixed AUROC`: chênh lệch AUROC giữa NAS và fixed baseline.
