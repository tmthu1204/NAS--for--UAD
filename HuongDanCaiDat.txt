HƯỚNG DẪN CÀI ĐẶT
=================

1. Công cụ và môi trường khuyến nghị
------------------------------------
- Hệ điều hành: Windows 10/11, Linux hoặc macOS.
- Terminal khuyến nghị trên Windows: PowerShell.
- Git để clone source code từ GitHub.
- Python: khuyến nghị Python 3.10 đến 3.12.
- GPU NVIDIA/CUDA: khuyến nghị để chạy full experiment. Nếu không có GPU, vẫn có thể đổi `--device cuda` thành `--device cpu`, nhưng thời gian chạy sẽ lâu hơn đáng kể.

2. Lấy source code
------------------
Clone repository:

git clone <URL_GITHUB_CUA_BAN>
cd NAS--for--UAD

Nếu nhận source dưới dạng file nén, giải nén và mở terminal tại thư mục gốc có các file/thư mục sau:

README.md
requirements.txt
setup.py
src/
scripts/
HuongDanCaiDat.txt
HuongDanSuDung.txt

3. Tạo môi trường ảo
--------------------
Windows PowerShell:

python -m venv venv
.\venv\Scripts\Activate.ps1

Linux/macOS:

python3 -m venv venv
source venv/bin/activate

Nếu PowerShell không cho activate môi trường ảo, chạy một lần:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Sau đó đóng/mở lại PowerShell và activate lại môi trường ảo.

4. Bật UTF-8 trên Windows
-------------------------
Các file hướng dẫn và một số thông báo có tiếng Việt có dấu. Trên Windows nên bật UTF-8 trước khi chạy:

$env:PYTHONUTF8='1'
chcp 65001

5. Cài đặt thư viện
-------------------
Sau khi activate môi trường ảo, chạy:

python -m pip install --upgrade pip
python -m pip install -r requirements.txt

Nếu dùng GPU NVIDIA và cần cài lại PyTorch bản CUDA phù hợp với máy, có thể cài theo trang chính thức của PyTorch. Ví dụ với CUDA 11.8:

python -m pip install --upgrade --force-reinstall torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

Nếu chỉ chạy CPU, thông thường cài `requirements.txt` là đủ.

6. Kiểm tra cài đặt
-------------------
Chạy các lệnh sau:

python -c "import torch, numpy, sklearn, pandas, scipy; print('torch=', torch.__version__); print('cuda=', torch.cuda.is_available())"
python -m src.pipeline --help

Nếu lệnh `--help` hiển thị danh sách tham số, môi trường đã sẵn sàng.
Nếu gặp lỗi `ModuleNotFoundError: No module named 'numpy'`, nghĩa là chưa activate đúng môi trường ảo hoặc chưa cài `requirements.txt`.

7. Chuẩn bị dữ liệu
-------------------
Dữ liệu raw và dữ liệu đã tiền xử lý KHÔNG đưa lên GitHub vì dung lượng lớn. Người chạy đặt dữ liệu vào các thư mục sau.

SMD:

data/ServerMachineDataset/
  train/
  test/
  test_label/

Hoặc:

data/ServerMachineDataset/
  train/
  test/
  labels/

HAI 21.03:

external/hai/hai-21.03/
  train*.csv hoặc train*.csv.gz
  test*.csv hoặc test*.csv.gz

Có thể đặt ở `data/hai_raw/` hoặc `external/hai/`; script sẽ tự dò layout phổ biến.

Exathlon:

external/exathlon/data/
  ground_truth.csv
  raw/
    app*/
      *.csv hoặc *.zip

Hoặc đặt ở `data/exathlon_raw/`, miễn là có `ground_truth.csv`/`ground_truth.zip` và các thư mục `app*`.

8. Thư mục sinh ra khi chạy
---------------------------
Các thư mục sau do chương trình tạo ra:

data/
external/
outputs/
results/
runs/
tmp/
tmp_smoke/
tmp_rule_tryouts/
venv/
.venv/
__pycache__/

Nếu muốn chạy lại từ đầu, có thể xóa các thư mục output/cache này sau khi đã sao lưu kết quả cần thiết.
