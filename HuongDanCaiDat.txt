HƯỚNG DẪN CÀI ĐẶT
==================

1. Yêu cầu
-----------
- Hệ điều hành: Windows 10/11, Linux hoặc macOS.
- Python 3.12 (khuyến nghị đúng phiên bản 3.12 để khớp môi trường thí nghiệm).
- Git và ít nhất 10 GB dung lượng trống cho môi trường Python, dữ liệu và kết quả.
- GPU NVIDIA được khuyến nghị cho thí nghiệm đầy đủ. Có thể chạy CPU nhưng sẽ rất lâu.

Repo đã chứa sẵn 28 cặp dữ liệu tiền xử lý dùng trong Chapter 4:
- SMD: 12 cặp.
- MSL: 6 cặp.
- SMAP: 10 cặp.

Không cần tải raw dataset và không cần chạy lại bước tiền xử lý hoặc chọn cặp.

2. Tải source code
------------------
Nếu dùng Git:

git clone https://github.com/tmthu1204/NAS--for--UAD.git
cd NAS--for--UAD

Nếu tải trực tiếp file ZIP, dùng đường dẫn:

https://github.com/tmthu1204/NAS--for--UAD/archive/refs/heads/main.zip

Giải nén rồi mở terminal tại thư mục NAS--for--UAD-main có các file:

requirements.txt
run_chapter4.py
src/
scripts/
data/chapter4/
reference_results/chapter4/

3. Tạo môi trường ảo
--------------------
Windows PowerShell:

py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1

Linux/macOS:

python3.12 -m venv .venv
source .venv/bin/activate

Nếu PowerShell chặn lệnh activate, chạy một lần:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Sau đó mở lại PowerShell và activate môi trường.

4. Cài thư viện
---------------
Nâng cấp công cụ cài đặt:

python -m pip install --upgrade pip setuptools wheel

Máy CPU:

python -m pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt

Máy có GPU NVIDIA, dùng bản CUDA 11.8 giống môi trường thí nghiệm:

python -m pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cu118
python -m pip install -r requirements.txt

Nếu máy dùng phiên bản CUDA khác, chọn lệnh PyTorch phù hợp trên trang chính thức
https://pytorch.org/get-started/locally/ nhưng vẫn giữ PyTorch 2.7.1 nếu có thể.

5. Kiểm tra cài đặt và dữ liệu
-----------------------------
Chạy:

python run_chapter4.py --check-only

Kết quả hợp lệ phải kết thúc bằng:

Environment and Chapter 4 data check: OK

Lệnh này kiểm tra phiên bản Python, dependency, ba manifest và mở thử toàn bộ
112 file NPZ của 28 cặp để phát hiện file thiếu hoặc hỏng.

6. Kiểm tra chạy nhanh
----------------------
Chạy một cặp SMD với cấu hình rút gọn trên CPU:

python run_chapter4.py --dataset smd --device cpu --quick

Chế độ --quick chỉ dùng để kiểm tra luồng chương trình, KHÔNG tạo kết quả trong
luận văn. Cách chạy thí nghiệm đầy đủ nằm trong HuongDanSuDung.txt.

7. Lỗi thường gặp
-----------------
- Python 3.13/3.14: tạo lại môi trường bằng Python 3.12.
- ModuleNotFoundError: activate đúng .venv rồi cài lại requirements.txt.
- CUDA unavailable: chạy --device cpu hoặc cài đúng PyTorch CUDA và driver NVIDIA.
- Thiếu data/chapter4: tải lại repo đầy đủ; không dùng tùy chọn tải bỏ qua file lớn.
- PowerShell hiển thị sai tiếng Việt: chạy chcp 65001 trước khi đọc file hướng dẫn.
